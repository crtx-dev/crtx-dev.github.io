Convenient browser access

my.crtx.dev is a memorable shortcut to your Cortex instance. It saves you from remembering port 7331 or repeatedly typing a localhost address and port.

Open Cortex

  1. Visit my.crtx.dev?config.
  2. Leave the defaults for a local Cortex instance, or enter the domain or IP address and port of a remote instance.
  3. Select Save, then Open.

After that, visiting my.crtx.dev forwards directly to the saved Cortex address.

The setting belongs to this browser.The destination is stored locally in your browser profile. Configure it again when using another browser, profile, or device. Use the ?config address whenever the Cortex host or port changes.

Default address

http://localhost:7331

The shortcut does not proxy Cortex or change its network exposure. It only opens the address you configure, so remote instances should still use the secure deployment guidance in Remote use.
